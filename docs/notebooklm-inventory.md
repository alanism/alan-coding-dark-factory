## Use Through NotebookLM MCP

This catalog is the discovery layer for ACDF's public NotebookLM workflow. For a coding reference guide or Hero Lens extraction:

1. Select a notebook row that matches the project, framework, or council domain.
2. Copy the complete public **Share Link** from that row into the configured NotebookLM MCP connection.
3. Use the MCP connection in read-only mode to ask the approved extraction questions; do not upload private project data into a public notebook.
4. Record the notebook title, ID, share link, extraction date, rounds, and source gaps in the resulting guide or card.
5. Keep raw answers and final artifacts in the change's evidence/reference area; commit only source-safe material.

The public URL is an input reference, not an authority grant. MCP access must not be used to bypass ACDF trust zones, approval records, content-hashed authority, or verification gates. If the MCP server is unavailable, stop and use the approved local extraction path documented in the relevant process guide rather than guessing a substitute integration.
