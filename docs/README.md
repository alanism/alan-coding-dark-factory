# ACDF Knowledge Sources

This directory contains the public NotebookLM inventory and the extraction processes used to produce coding reference guides and Hero Lens cards.

- [NotebookLM inventory](notebooklm-inventory.md) — public shared notebooks grouped by council and domain.
- [Coding reference guide process](coding-reference-guide-process.md) — turn a selected notebook into a source-backed guide through NotebookLM MCP.
- [Hero Lens card process](hero-lens-card-process.md) — extract and synthesize individual Engineering and Design Council cards.
- [Approval policy template](../templates/APPROVAL_POLICY.md) — choose human-led or Council-led decisions and define hard stops.

Use only the public share link listed in the inventory when connecting through NotebookLM MCP. Do not add private notebooks, credentials, source files, or session tokens to this repository.
