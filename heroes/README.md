# Engineering Council — Start Here

Advisory lenses for bounded work. Use the council for planning, adversarial review, implementation, QA, integration and learning, inside or outside ACDF. In ACDF execution, the approved plan controls scope; upstream planning must be explicitly assigned. Cards cannot grant permissions or approval authority.

1. Read project instructions and the approved handoff.
2. Select no lens for a straightforward task, or one primary lens below.
3. Read [the shared routing and handoff guide](how-to-use.md) and the selected card. Add another only for a distinct necessary concern. Do not preload the entire library.
4. Run the approved checks and retain evidence. Record what was loaded and what helped.
