# ACDF Learn — Engineering Thinking in the Age of AI

Welcome to **ACDF Learn**. This is not software documentation or API references—this is a curriculum designed to teach you how to think like a systems engineer. 

Whether you are a designer, a teacher, a teenager, an artist, or a professional changing careers, this guide will build your engineering judgment from the ground up.

---

## 1. Educational Philosophy

Following a conceptual-first learning philosophy, we never start with syntax, programming languages, or developer tools. We focus on building understanding first.

Every lesson is structured around:

```
Mental Models ──► Visualization ──► Practice ──► Reflection ──► Mastery
```

1. **Big Picture**: Real-world analogies explaining why a concept exists.
2. **Mental Model**: The core concept to picture in your head.
3. **Visual Thinking**: Mermaid diagrams mapping system architecture and sequences.
4. **Build Something**: A tiny, hands-on, working project.
5. **Hero Lens Critique**: Evaluating your work through different expert doctrines.
6. **Reflection**: Questions to help you consolidate your learning.
