# Welcome to ACDF Learn

Welcome! If you have never built software before, or if you feel intimidated by command lines, compilers, and code syntax, you are in the right place. 

## The Big Picture

Imagine you want to build a house. You wouldn't start by digging a random hole in the ground and laying bricks. If you did, the house would likely collapse. Instead, you would:
1. Talk to the family to understand their needs (how many rooms? garage?).
2. Draw blueprints to map the structural layout.
3. Validate the blueprint against building codes.
4. Hire specialists (plumbers, electricians) to build sections.
5. Inspect the finished sections before moving in.

Building software works exactly the same way. Coding is just the construction phase—but the planning, the blueprints, and the inspections are where real engineering happens. ACDF (Alan Coding Dark Factory) is an operating system that guides you through these phases.

---

## What is this Curriculum for?

This course is designed to teach you **how to think like a systems engineer** in the era of artificial intelligence. We will teach you how to write precise instructions, model systems visually, stress-test your plans using AI advisors, and govern automated coding tools safely.

---

## How to Use this Guide

* **Step by Step**: Do not skip lessons. Each lesson builds on the previous one's mental model.
* **No Syntax Required**: In the first few lessons, you won't write a single line of code. You will draw diagrams and define rules.
* **Use the Reflections**: At the end of each lesson, take a moment to answer the reflection questions. The habit of reflection is what separates great engineers from coding machines.
