# Alan Coding Dark Factory (ACDF) v8

Alan Coding Dark Factory (ACDF) is an autonomous, sequential, and gate-governed AI engineering operating system. It enforces software quality, containment boundaries, and continuous organizational learning during agent execution.

## Core Axiom

ACDF acts as an execution container. Unlike fluid specifications, ACDF requires strict progression through stages 0 to 8, validating binary gates and compiling runtime evidence before allowing code modifications.

## Repository Layout

* `framework/`: The core protocol kernel rules.
* `schemas/`: Machine-readable JSON Schemas for validating authority, tasks, claims, and receipts.
* `templates/`: Gated workspace directory templates for target projects.
* `examples/`: Golden example walking through the ACDF v8 lifecycle.
* `scripts/`: Verification scripts enforcing repository integrity.

## Evolving Hero Lenses

ACDF's primary differentiator is the **Hero Lens**—a living knowledge module synthesized from curated expert engineering corpora (papers, codebases, lectures) managed via NotebookLM. These lenses act as advisory guides, mapping failure modes and design heuristics to active build phases.
